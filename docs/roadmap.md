## Future enhancement: unified CLI

Turn the toolkit into a single CLI so users install one command and access every tool from a unified interface, instead of running dozens of separate scripts:

```
devops-toolkit docker cleanup
devops-toolkit k8s logs
devops-toolkit aws inventory
devops-toolkit azure report
devops-toolkit ssl check example.com
devops-toolkit disk cleanup
```
